# APMCApp

Production-oriented Agricultural Produce Market Committee (APMC) application.

## Stack
- Backend: Django + Django REST Framework
- Database: PostgreSQL
- Frontend: React + Tailwind CSS
- Authentication: JWT
- Authorization: Role and permission based

## Development order
1. Backend foundation
2. Authentication
3. Authorization
4. React + Tailwind
5. Role-based dashboards
6. APMC business modules
7. Testing
8. Docker/deployment
